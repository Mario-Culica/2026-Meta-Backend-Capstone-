# 2026-Meta-Backend-Capstone-

A restaurant management application built with Python and Django.

Technologies Used: Python, Django, Django REST Framework, MySQL, Djoser and Token Authentication, Insomnia, Git and GitHub

Running the project:

After cloning the repository, create and activate a virtual environment, install the required packages, and configure the database connection in Django settings.

Run the migrations:

python manage.py migrate

Start the development server:

python manage.py runserver

Running the tests:

From the project root, run:

python manage.py test tests

The menu model and menu API tests are included in the tests folder.

What I learned:

Working on this project helped me practice building APIs with Django REST Framework, connecting models to serializers and views, handling authentication, and testing endpoints with both Django's test framework and Insomnia.
